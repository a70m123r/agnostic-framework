## §1 — Verdict

A strong, unusually self-aware **skeleton** whose central instrument — heredity and niche-presence as settable classifiers read at matched `{plane, observer, frame}` settings, scored by toggle **co-variation** and returned as a **sweep** not a verdict — is recognized by all five lenses as a genuine methodological advance and a faithful rendering of Pav's "classifier not a fact / dial-or-toggle" steer. **But it is not lockable as written.** The falsifiable content — the predictions, the scoring statistic, the substrate corpus, the closed-form estimators, and the artifact contract — is still owed. Locking it as-is would lock *a test that cannot fail and an input contract that cannot be executed.* Three independently-corroborated **blocking** faults sit at the centre; below them are major scoring/identification faults and a set of blind spots the completeness pass surfaced.

## §2 — Blocking faults (multi-lens, file-verified)

**B1 — The headline PASS/FAIL statistic is structurally starved of FAIL outcomes.** *(methodology + adversary)*
The substrate set is selected on the very property under test (units of selection), the retained non-UNDEFINED cells are pre-filtered to be ABOVE/PRESENT, `NICHE-ABSENT` can be recorded only if the unsolved exogenous effort-proxy ≥ floor (N.7.2), and abundant co-UNDEFINED cells count as agreement. Net: the effective base rate of PRESENT → 1 and the test can almost only return PASS or INCONCLUSIVE *for measurement reasons unrelated to whether §5.1-R is true.* No null distribution is specified, so no τ_pass threshold is interpretable. Adversary reaches the same place via a **unit-of-analysis slip**: §5.1-R is about *substrates* but H.7 scores concordance over *grid cells*, so the statistic is dominated by how finely each substrate is decomposed and by the co-UNDEFINED diagonal (shared domain-of-applicability, not the law).
→ Re-cast as a conditional, falsifier-relevant statistic; remove co-UNDEFINED from numerator AND denominator; pre-register a permutation null; require a minimum count of genuinely-ABOVE, recordable-ABSENT-possible cells or INCONCLUSIVE by rule.

**B2 — The two instruments are calibrated on a single shared anchor where they are one physics read twice.** *(methodology + adversary + fidelity)* **[file-verified, sketch line 944/942, N.3]**
The heredity gate's machinery *is* §RS Conjecture-B (Eigen error threshold `Q_c = 1/a`, quasispecies, Price covariance); niche mode-i's strongest PRESENT exemplar is the *same* RNA-world Eigen parasites. The inequality that defines whether heredity holds is the inequality whose violation is the parasite takeover — one quasispecies physics, not two measurements. Deeper than the self-flagged tautology knob (N.7.1, which only addresses the *definition* of beneficiary). The recommended persistence-only fix is **empirically vacuous**: every headline positive (RNA parasites, Qβ/MDV-1, transposons, prions) is a heredity-needing *propagator*, and the clean negative (a persistence-only beneficiary at a non-heritable substrate) is exactly what the §5.1 search already found NONE of.
→ Exclude the molecular cell from the scored set, or require its PRESENT reading from a quantity provably orthogonal to Q; force the lock to NAME a concrete persistence-only-at-non-heritable candidate or disclose the branch carries zero falsification mass; specify the unit-identity rule (is Q measured on the same entity as the niche beneficiary, or on the host order?).

**B3 — The protocol's central binding claim does not execute against the artifacts.** *(integration + methodology)* **[file-verified]**
WORKFLOW §3.1 says instruments consume `compiled/*.json`; §2 maps the dial axes onto `frame_layer` / `actors[].kind` / `frame[]` / graded membership. A grep of `internet.compiled.json` returns **0** for every one of those structural terms; the same grep on `specimens/internet.json` returns 54 for `frame_layer` alone. `compile_substrate.py` (write_compiled_exports, ~line 371) emits only `subject → {predicate, value, when, bucket, certainty, source, provenance_refs}` and harvests structural fields from the base specimen for subject-id **validation only** — it never copies them. So an instrument obeying §3.1 cannot evaluate a single dial axis. Worse, the frame-lock SHA covers the compiled snapshot, which does **not** contain the structural fields the readings depend on — so "the dial is the thing you lock" (H.6) is incompletely realized: a post-hoc edit to a base specimen's `frame_layer` would change every reading without breaking the locked hash.
→ Either extend the compiler to fold the structural fields into the compiled export (preferred — makes "one committed contract" true and the snapshot hash sufficient), or declare a two-input contract (structure from specimen + provenance from compiled) and lock the base-specimen snapshot too. Do not lock while §2 and §3.1 reference different artifacts.

## §3 — Major consensus findings

- **M1 — No inter-rater protocol, no blinding, no null; the `nameable beneficiary/cost` toggle is single-analyst judgment by the believing framework.** *(methodology + adversary)* Frame-lock disciplines *which* settings but not the interpretive freedom *inside* each cell; locking your predicted toggle does not lock the evidentiary standard for the prediction. → Two coders blind to the heredity reading + a written coding manual + Cohen's kappa (disagreements → NO-CALL); heredity coder blind to niche output; route niche readings through the owed external model to make N.9's "specifiable by an outsider" a procedure, not an aspiration.
- **M2 — Co-variation is necessary but NOT sufficient.** *(adversary + methodology)* A confound common to both instruments (substrate age / study-volume / documentation density, or shared domain) manufactures a spurious PASS; the effort proxy guards only survivorship. No common-cause control, no placebo, no "heredity-ABOVE-but-niche-ABSENT-would-be-surprising" hard case. → Detrend both toggles on a shared-attention covariate and require the association to survive; pre-register a hard case; state necessary-not-sufficient in H.7.
- **M3 — Dial value → SCHEMA_v2 graded membership erases metric semantics AND inherits PROXY_SPEC's "illustrator, not a measuring instrument" disclaimer.** *(adversary + integration)* **[file-verified]** Q (a probability tied to `Q_c=1/a`) and E (a leverage ratio `n·KL/−log a`) have units and a theory; membership is "weights, not hard values." PROXY_SPEC carries the verbatim disclaimer; declaring the instruments "a new instance of that pattern" inherits it, demoting a phase-boundary claim to decorative blobs. Plus the fact-path caps derived proxies ≤0.6 (`compile_substrate.py` ~line 175) while the proxy-path does not — and the DRAFT invokes both. → Store Q/E as first-class measured facts with units + estimator + certainty; explicitly repudiate the illustrator clause for these channels; pick one certainty path.
- **M4 — H.7 and N.1 give contradictory rules for scoring UNDEFINED cells; UNDEFINED is itself overloaded across three states.** *(methodology + adversary)* H.7 counts UNDEFINED-heredity on the absent side (concordant); N.1 excludes co-UNDEFINED entirely. And UNDEFINED conflates ontological-ill-posed (heredity: no replicator), ontological-about-another-object (niche: no compiled order), and epistemic NO-CALL (didn't look). → Tabulate co-UNDEFINED as a separate out-of-scope-agreement count that cannot move PASS/FAIL; keep epistemic NO-CALL distinct from ontological ILL-POSED; only DEFINED-and-BELOW cells populate the absent arm.
- **M5 — E is undefined in exactly the mode-i cells where niche reads PRESENT strongest; `Q_c=1/a`'s "a" is undefined on the latent plane; and E and Q_c share the same "a", coupling the "independent" instruments.** *(methodology + adversary)* **[file-verified]** mode-i is "no represented model present" → KL numerator undefined; latent "a" ("selective advantage of the master variant of an oral epic?") is a free parameter; estimation error in shared "a" propagates correlatedly into both, inducing spurious co-variation. → Per-mode E (mode-i = resource/thermodynamic capture ratio, no KL; mode-ii = KL-leverage), domain-stamped in CENSUS_PROXY_SPEC; define "a" per plane incl. a procedural latent "a", else report latent toggle DIAL-ONLY and don't score latent cells; source E's "a" separately from Q_c's or model the correlation.
- **M6 — The "matched settings" rule can manufacture false UNDEFINEDs and false concordances when the beneficiary individuates at a different observer level than the replicating unit; and plane×frame are not orthogonal, so much of the grid is uninstantiable.** *(methodology + adversary)* A 2×8×3 nominal grid may reduce to a dozen scorable discriminating cells — a small-N study in a large-grid costume. → Define concordance on the `(plane, frame)` cell, or flag `beneficiary-individuated-elsewhere` for sensitivity testing; enumerate the actually-instantiable cells before locking and report that as the real grid size.
- **M7 — Register over-claims.** *(discipline + fidelity)* **[file-verified]** N.4 "That agreement, swept across the grid, IS the §5.1-R test" and H.4 "one bit could never have said that" both claim a win before measurement, over cells labelled NOT-locked; WORKFLOW calls the stack "already-ratified" when only SCHEMA_v2 is ratified, and only as a TOOL. → Soften to claim the *design* not the result; reword to "mostly-ratified (SCHEMA_v2 as a TOOL; SUBSTRATE_SPEC/PROXY_SPEC/VIEWER_SPEC still Tier-3)."

## §4 — Blind spots (high-value singletons)

- **BS1 — CLAIM_LIFECYCLE makes the PARENT conjecture structurally unfalsifiable at the programme level.** *(adversary — "deepest structural critique; the other four lenses missed it entirely")* Each census is locally falsifiable, but every FAIL is absorbed as "that grid/those estimators were wrong"; with unbounded interpretive freedom there's an unbounded supply of children to spend, and nothing specifies the N at which the tally IS a refutation. → Pre-commit a refutation budget **K**: K *evidential* dead children (data-contradicted, not logic-error) → parent RETIRED, not perpetually PARKED. Distinguish engineering-bug children (don't count) from data-contradicted children (do).
- **BS2 — A census substrate is not a SCHEMA_v2 specimen at all.** *(integration)* **[file-verified, SCHEMA_v2 §0 line 111 + design law]** A specimen is *one merge event* with a mandatory `child + weld.parents + when + status` trunk; a hurricane field / RNA-world population has no weld, no two parents, no child. "Records the census substrate as a specimen conforming to SCHEMA_v2" is a **category error**, not a tight binding. → Decide explicitly: a ratified schema-*variant* carve-out (frame machinery without the weld trunk), or a native census node shape reusing only the substrate-agnostic fact-log/compiler/verification.
- **BS3 — The "frame" dial axis silently redefines Pav's term-of-art.** *(fidelity)* **[file-verified]** H.1 "frame" = copy-event lens `{strict-replicator, broad-reproducer, information-channel}`; Pav's "frame" = the observer global kernels `{time, space, knowledge, meaning}`. WORKFLOW §2 asserts these map one-to-one; they don't. → Rename the copy-event axis (e.g. `copy-lens`); keep `{time,space,knowledge,meaning}` as a separate (currently unswept) axis; translate back to Pav explicitly.
- **BS4 — §5.1-R is operationalized purely through Conjecture B of the deliberately non-convergent three-loci §RS, with the trilemma unacknowledged.** *(fidelity)* **[sketch line 944, 864]** A substrate could establish a candidate-reality via A-locus (action-sustained) or C-locus (publicity-flip) with B-style heredity Q low/undefined, and the instrument would score it BELOW-GATE / out of scope — silently crowning B in a contest Pav holds open ("None is crowned"). → Add a scope paragraph; offer Pav an `ESTABLISHED-NON-B` toggle state so A/C-locus establishment is not folded into BELOW-GATE.
- **BS5 — WORKFLOW carries no "external A− owed" caveat though both siblings do and it is the most structurally ambitious of the three.** *(discipline)* It even offers to graduate to a canon-level standard governing all instruments. → Add the caveat and make it gate the graduation sentence.

## §5 — What the whole panel still missed (completeness pass)

- **PM1 — "concordance" is never mathematically defined anywhere in the three DRAFTs.** τ_pass/τ_fail threshold an unnamed statistic (raw agreement? kappa? conditional probability?) — the choice dominates the verdict and is upstream of every scoring critique. `lock_brief_2.yaml` has fields for the thresholds but none for the *statistic*.
- **PM2 — The census substrate corpus does not exist and may not be constructible.** **[file-verified]** The current 7 compiled substrates (darwin-mendel, deep-learning, internet, keynesian, manhattan, maxwell, quantum-gravity) are **100% intellectual-history theory-merges**; none is a hurricane / RNA-world / immune system. The "validate on toys" and "real-substrate run" steps presuppose a corpus that doesn't exist and (per BS2) may not be expressible in the bound schema. The bind-don't-fork reuse claim is being made against a substrate set with zero instances of what the census measures.
- **PM3 — The plane binary drops SCHEMA_v2's third `frame_layer` value `straddle`.** **[file-verified, line 182/339]** And H.3's own artefact-viroid coupling note (latent payload on a physical anchor) is exactly a straddle case — forced into two separate cells, mechanically generating off-diagonal UNDEFINEDs that feed the co-UNDEFINED concordance inflation. The dial grid is strictly coarser than the schema it claims to bind to on the most load-bearing axis.
- **PM4 — ABSENT is at least two categories needing different admissibility rules.** Empirical-search-negative (software-ecosystem cell, effort-floor gated) vs conceptual-clean-negative (hurricane / single star — "no beneficiary even importing a fitness concept" is an a-priori judgment, not a corpus search). The N.7.2 effort-floor machinery does **not** apply to exactly the clean negatives the §5.1 argument most relies on — applying it there would force NO-CALL on hurricanes and collapse the negative class.
- **PM5 — The called-shots barely exist.** H.5/N.5 contain one illustrative called-shot each (oral epic; hurricane); the substrate enumeration is deferred. The frame-lock-pilot pattern derives its anti-gaming force from a *complete pre-registered prediction grid*; as written the predictions do not exist to be locked — the pre-registration is currently empty.

## §6 — Disagreements (and their resolution)

- **bind-don't-fork: sound vs broken.** Discipline/adversary read it as clean verified engineering; integration holds the *specific* §2 mapping rows + §3.1 input contract fail against the artifacts. **Resolution:** both true once scoped — the fact-log/compiler/verification reuse binds cleanly (real, substrate-agnostic); the four §2 dial-axis mappings are broken (ground-truth-verified). Side with integration on the mappings; keep the others' correct read that the underlying reuse strategy is sound.
- **persistence-only: rescues vs relabels.** Fidelity credits the design intent; methodology/adversary stress empirical hollowness. **Resolution:** the knob was correctly identified and the setting is right *in principle*, but the lock must force a named concrete persistence-only candidate or disclose zero falsification mass.
- **frame-lock: adequately described vs adequately binding.** Discipline judges the description faithful (only the "§7" pointer is a propagated citation error); adversary/methodology/integration judge the *binding* incomplete (interpretive freedom inside cells; the hash doesn't cover the structural fields). **Resolution:** complementary — "described correctly" ≠ "adequately binding."

## §7 — What held up (consensus strengths)

1. The **core reframe** (classifiers at matched settings, co-variation, sweep-not-verdict) — all five lenses: a genuine disciplined advance and a faithful, near-verbatim rendering of Pav's steer.
2. The **anti-gaming backbone** (one lock, one grid, matched settings, report-every-cell, the asymmetric ABSENT-needs-effort-proxy survivorship discipline) — correctly identifies the unsolved denominator without pretending it's solved.
3. **Naming the tautology knob** is the single most important piece of methodological self-awareness; the critique is "necessary-but-not-sufficient," not "missed."
4. **UNDEFINED-as-floor** ("no q to ask about") is the methodologically correct representation; the problem is only how UNDEFINED flows into the score.
5. The **CLAIM_LIFECYCLE FAIL-branch** is named correctly and consistently (parent survives / child dies / +1 tally / claim frozen) — with the one caveat that the programme-level budget K is missing (BS1).
6. The **provenance / no-fabrication machinery being reused is genuinely substrate-agnostic and binds cleanly** — the strongest real part of the integration, distinct from the contested §2 mappings.
7. The **bind-don't-fork instinct** is right as engineering, and the **honesty register** is consistently high where it self-reports (the unsolved denominator, the conjectural latent transfer, the failing toys are all surfaced in-text, not smuggled).

## §8 — Ranked top changes (the path to lockable)

1. **Re-specify the scoring statistic first.** Define "concordance" mathematically; re-cast as conditional `P(niche-PRESENT | heredity-ABOVE-and-defined)` vs `| BELOW-but-defined`; drop co-UNDEFINED from both numerator and denominator; add a STATISTIC field (not just thresholds) to `lock_brief_2.yaml`; pre-register a permutation/label-shuffle null; require a minimum effective sample else INCONCLUSIVE-by-rule. *(B1 + PM1)*
2. **Resolve the §2-vs-§3.1 artifact contradiction.** Fold the base-specimen structural fields into the compiled export (preferred) or declare a two-input contract; make the frame-lock SHA cover whatever the instruments actually read. *(B3)*
3. **De-circularize the calibration anchor.** Exclude the molecular cell or measure niche there orthogonally to Q; name a concrete persistence-only-at-non-heritable candidate or disclose zero falsification mass; specify the unit-identity rule. *(B2)*
4. **Add a nameability + blinding protocol** (two blind coders, coding manual, kappa; route niche through the external model). *(M1)*
5. **Fix the estimators undefined in the anchoring cells** (per-mode E; per-plane "a" incl. latent or DIAL-ONLY; decouple E's "a" from Q_c's). *(M5)*
6. **Scope the claim honestly** — v0 tests only the co-presence arm; drop/hold "essentially at the first opportunity"; add the Conjecture-B-only scope + an `ESTABLISHED-NON-B` state. *(M2-adjacent + BS4 + "first opportunity")*
7. **Settle schema-conformance + corpus** — decide native census shape vs SCHEMA_v2 carve-out; confirm the census corpus is constructible (the existing 7 are all theory-merges); add the `straddle` plane value. *(BS2 + PM2 + PM3)*
8. **Tighten discipline/register edges** — add refutation budget K; split ABSENT into empirical vs conceptual; soften the two over-claim lines; reword "already-ratified"; add the WORKFLOW external-A− caveat; fix the propagated "§7" citation. *(BS1 + PM4 + M7 + BS5)*

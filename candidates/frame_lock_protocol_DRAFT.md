# Frame-Lock Protocol (v2, stress-hardened) for PPWc(W_A, W_B | frame)

Tier-3 WORKING DRAFT for Cowork+Pav ratification — NOT canon, NOT a tier promotion; the cross-substrate convergence list stays at **9**. A single ordered pre-registration discipline a submitter follows top-to-bottom, built on the Pilot-2 precedent (falsifier committed to git before data; `audits/v08.md §C7`). This protocol closes the single remaining hole on `PPWc` named by a triple convergence (GPT-5.5, Gemini, internal validation; `parents_produce_WC_FORMALIZATION_DRAFT.md §4`): **PPWc is gameable by FRAME-SHOPPING and RESOLUTION-SHOPPING, and by the two-co-equal-parents-vs-one-parametrized-operator ambiguity, UNLESS the frame, the category, the span morphisms, the coding scheme, the measurement resolution, AND the strict-vs-generous synergy reading are all LOCKED before W_C is examined.**

## 1. The lock file (`lock.yaml`) — one file per parent pair

A header (fields 0,1,15) plus, FOR EACH declared frame, a complete sub-lock block (fields 2f–14f, including the two new fields **9f-bis** and the extended **13f**). Every field mandatory and concrete; `TBD`/blank/`see below` makes the lock INVALID. Single threshold symbol: `base_delta` (= τ), with the effective per-frame bar **τ_eff = base_delta + log2(k)**, k = |frames_declared|.

**Header**
- **(0)** submission_id / version / parent names / S label.
- **(1)** `frames_declared` — non-empty subset of {time, space, knowledge, meaning}; declaring k frames raises τ_eff on ALL of them by log2(k) bits.
- **(15)** `base_delta`; `lock_content_hash = sha256(fields 0–14, incl. 9f-bis)`; `lock_commit` + committer-date; optional external anchor `T_lock`.

**Per declared frame f**
- **(2f)** frame token (a single member of the set).
- **(3f)** `C_frame`: objects + morphisms, named explicitly (closes `§3` core-hole "name the morphisms, not just the kernel").
- **(4f)** `W_A`, `W_B` as explicit codes, declared at the **coarsest physically-realized kernel grain of the SAME token of matter/structure that instantiates W_C** (P3a). Idealizing a parent finer than the child's realized grain (e.g. single-crystal parents under a bulk-specimen W_C) is a PARENT/CHILD GRAIN MISMATCH → INADMISSIBLE.
- **(5f)** `S` as an explicit object, declared at its **coarsest faithful grain** (P3a, symmetric leg) AND satisfying **FRAME-PURITY** (P5a): in a single-frame sub-lock, S must be closed under (2f)'s morphisms ONLY, and S's *existence* must not invoke another frame's kernel. For {space}, S must be co-present and shared at a single spatial instant and must NOT be the product of a time-ordered process. (A cemented/reaction-rim interface is manufactured by diagenesis over time → declaring it as a {space} S imports time-kernel content → INVALID. See §5c.)
- **(6f)** span `i_A, i_B` as explicit maps `S → W_A`, `S → W_B`.
- **(7f)** coding scheme `enc(.)` + pinned content-addressed compressor + native bit-precision; the parents and W_C are coded at the grains fixed in (4f)/(5f)/(8f).
- **(8f)** **DERIVED resolution band** with a child-anchored ceiling (P3b):
  - `r_floor` = S-faithfulness grain (the finest grain at which S is still a faithful sub-object);
  - `r_top` = **W_C-faithfulness ceiling** = the coarsest grain at which W_C ITSELF is still a faithful object of C_frame (NOT the parents' grain);
  - band = `[r_floor, r_top]` + an explicit evaluation grid that **must include the grid point r_top**.
- **(9f)** synergy threshold rule: `Syn(r) ≥ τ_eff` at every grid point in the band, **including r_top**.
- **(9f-bis)** **NON-ADDITIVITY WITNESS** (P1) — NEW, mandatory. Name a frame-coded observable `O` of W_C that is **invariant under unitary/linear re-coordinatization of `H_A ⊕ H_B`** and is provably **NOT** a function of any single parent's marginal plus a bounded change-of-basis. Formally: Syn must remain `≥ τ_eff` after quotienting out the group of linear re-coordinatizations of the parent direct sum. The lock must cite the witness explicitly (e.g. LCAO cites bond order = ½(n_bond − n_anti)).
- **(10f)** precommitted W_C-construction rule (the deterministic recipe that yields W_C from the locked span).
- **(11f)** parent-count sibling classes + the declared back-reaction / state-dependence threshold and grid.
- **(12f)** parent-symmetry / co-equality attestation — attesting the **state-dependence + force-balance** pair of (3 / Clause 2), NOT an "internal-state writeback" that energy-functional parents structurally cannot exhibit (P2).
- **(13f)** one-line mechanism rationale **+ CALLED-SHOT** (P4): a binary pre-predicted outcome for THIS frame, `predicted ∈ {predicted-PASS, predicted-NULL/FAIL}`, recorded before W_C is examined.
- **(14f)** per-frame PASS/FAIL/NULL predicate over ONLY declared quantities.

## 2. Procedure (top to bottom)

- **STEP 0** — pick the parent pair + frames; pay the `log2(k)` honesty cost up front AND commit a called-shot prediction (13f) for every declared frame.
- **STEP 1** — fill `lock.yaml`: all header fields + every per-frame block (2f–14f, incl. 9f-bis).
- **STEP 2** — seal: compute `lock_content_hash` over fields 0–14 (incl. 9f-bis).
- **STEP 3** — commit. The commit IS the lock; anchor the hash externally (`T_lock`) for third-party tamper-evidence. The lock commit MUST be a strict ancestor of the first W_C MDL artifact.
- **STEP 4** — examine W_C only after STEP 3, gates in FIXED order per frame:
  - **(4a)** run the construction rule (10f).
  - **(4b) PARENT-COUNT GATE first** — Clause 1 (independent instantiability), **Clause 2 (state-dependence/exogeneity, restated — see §3)**, Clause 3 (swap test against pre-declared siblings). Any clause fails → FAIL at the gate, STOP for that frame.
  - **(4c) PUSHOUT NON-DEGENERACY** — no strictly-smaller object of C_frame receives `i_A, i_B` over S with the universal property.
  - **(4d) SYNERGY ACROSS THE DERIVED BAND** — `Syn(r) ≥ τ_eff` at every grid point in `[r_floor, r_top]` **including r_top**, AND the **non-additivity-witness quotient** (9f-bis) holds: Syn survives quotienting out linear re-coordinatizations of `H_A ⊕ H_B`.
  - Resolution/synergy is strictly downstream of parent-count and pushout, so it can only FAIL or stay-failed — never resurrect an upstream failure.
- **STEP 5** — evaluate the per-frame predicate (14f) → {PASS, FAIL, NULL}.
- **STEP 6** — seal `results.yaml` separately (a later commit quoting `lock_content_hash`; report ALL declared frames, each with its called-shot prediction and realized outcome).
- **STEP 7** — headline = the **called-shot-adjusted conjunction** of per-frame outcomes (§4), reported verbatim over ALL declared frames; no post-hoc narrowing to the one frame that passed.

## 3. The three gates, in order

### PARENT-COUNT GATE (conjunctive; decides ONLY arity) — restated Clause 2 (P2)

Two co-equal parents **iff** Clauses 1 + 2 + 3 all hold.

- **Clause 1 — independent instantiability.** Each parent is a standalone W-object with its own L0 kernel, instantiable without the other.
- **Clause 2 — state-dependence / exogeneity (restated, replaces the "internal-state writeback" locution).** A channel is **EXOGENOUS (not a parent) iff its contribution to the shared state is INDEPENDENT of the shared state** — i.e. `enc(channel output)` does not vary with the configuration `x` evaluated on the declared grid (11f). A channel is **co-equal iff its contribution is a non-constant function of the shared state** on that grid. This is the framework's own C-IT-3 / Data-Processing-Inequality hook ("no admissible internal computation raises KL without an injected signal"; `§2`, `BAR_A_SKETCH §IT C-IT-3`) read at the level of the shared-state force, not a private internal register — which is what energy-functional parents (ACMP) structurally lack.
  - **Two-body co-equality WITNESS (positive test, required when the candidate has a declared fixed point):** a non-trivial mutual force-balance at the declared fixed point, `F_A(x*) = −F_B(x*) ≠ 0`. The witness is the attestation in field 12f; span-symmetry is the *diagram-level* corroboration, not a fourth test.
- **Clause 3 — swap productivity.** Swapping either parent for a pre-declared sibling (11f) yields a structurally different fixed point / pushout; both slots are productive.

An additive blend **PASSES** this gate (components are genuinely two, state-dependent, swap-productive) and is killed DOWNSTREAM by synergy — keeping cymatics-FAIL (parent-count) and additive-FAIL (synergy) as separate routes. The named ambiguity "internal-state vs shared-state writeback" is flagged in §6 for ratification.

### PUSHOUT NON-DEGENERACY

No strictly-smaller object of C_frame receives `i_A, i_B` over S with the universal property (the candidate is not the degenerate pushout that collapses to S or to a parent). This is the `§1.A` universal-property hook.

### SYNERGY ACROSS THE DERIVED BAND + NON-ADDITIVITY WITNESS (P1, P3b)

`Syn(r) = min(K(W_C|W_A), K(W_C|W_B)) − K(W_C|W_A,W_B)`, surrogated by the MDL `ΔL` bits along the locked coder (7f), evaluated at every grid point in `[r_floor, r_top]`, each `≥ τ_eff`, **with r_top (the W_C-faithfulness ceiling) an explicit committed grid point**. The band is **DERIVED** from committed objects (S-faithfulness floor, W_C-faithfulness ceiling), reviewer-recomputable, not a free dial; moving the band requires changing S or W_C, which changes the diagram the reviewer re-checks.

Additionally (9f-bis), the surviving synergy must be carried by a **rotation-invariant non-additivity witness**: `Syn` must remain `≥ τ_eff` after quotienting out unitary/linear re-coordinatizations of `H_A ⊕ H_B`. A W_C that differs from the additive blend `a·W_A + b·W_B` only by a change-of-basis (mixing angle) has its synergy annihilated by the quotient → FAIL. This is the rule that adjudicates LCAO and coupled-plate cymatics identically (§5a).

## 4. Admissibility + reporting (checkable from lock + report alone)

**VALID iff:** all fields present and concrete (incl. 9f-bis and the 13f called-shot); each frame token a single member; self-hash recomputes; lock commit strictly precedes the W_C artifact; `lock.yaml` byte-identical across both commits; every predicate references only declared quantities; S satisfies frame-purity (5f); the band includes r_top (8f); `τ_eff = base_delta + log2(k)` for every frame.

**INVALIDATES (scores NO SUBMISSION):** any post-seal edit; results at/before lock time, or W_C read before `T_lock`; >1 frame token in a sub-lock; a second lock filed after results to swap/add a frame; changing coding/band/grid/threshold/span/siblings/construction/predicate/witness/called-shot between lock and results; an undeclared quantity in a predicate; **a parent/child grain mismatch (4f) or a cross-frame-contaminated S (5f)**; a missing r_top grid point (8f).

**CALLED-SHOT SCORING (P4) — the citable headline:**
- `headline_score = ( # frames where predicted-PASS was CONFIRMED ) − ( # frames declared predicted-PASS that did NOT pass )`.
- A frame predicted-NULL/FAIL that indeed fails/NULLs is a **free, documented null control** (no penalty, no credit). This preserves anchor (c): rocks declare `{time: predicted-PASS, space: predicted-NULL/FAIL}`, both predictions confirmed, headline intact.
- A frame predicted-NULL/FAIL that **SURPRISE-passes scores NULL, not PASS** — no citable credit for a result you bet against. This removes the free-lottery-ticket benefit that a flat `log2(k)` toll could not price.
- `log2(k)` remains on τ_eff as a SECONDARY anti-synergy-fishing term; it is no longer the sole or primary frame-shopping deterrent.

**EXHAUSTIVE REPORTING:** `set(reported frames) == frames_declared` exactly; the headline is the called-shot-adjusted conjunction of reported verdicts over the whole declared set.

**CONJUNCTION OVER NULL (P5b):** the per-frame verdict lattice is {PASS, FAIL, NULL}. For the headline conjunction, **NULL is the identity element** (a confirmed-NULL frame neither breaks nor inflates a multi-frame headline) and **FAIL is absorbing** (any predicted-PASS frame that FAILs drives `headline_score` down per the called-shot arithmetic). A mixed `{time: PASS, space: NULL}` report is therefore well-formed and yields a clean single-frame PASS headline with a documented space-frame null.

## 5. Anchor preservation (all four survive every patch)

### (a) CYMATICS FAILS in every frame — by mechanism, on a single pinned synergy reading

- **Textbook single-driver cymatics** (driver f + medium): FAILS at the parent-count gate in every frame. Clause 1 fails (f is a bare scalar, not a wrapper); confirmed by **restated Clause 2** — the function-generator's output (amplitude/frequency) is INDEPENDENT of the plate configuration, hence EXOGENOUS (P2 makes this the mechanism, replacing the empty "medium never writes onto f"); Clause 3 has no independent second slot (the only "swap" re-selects eigenmodes of one operator). FAIL at the gate, every frame.
- **Nonlinear coupled-plate (Faraday, large-amplitude)** — the smuggler's relabel: pattern selection is governed by drive amplitude/frequency, so the exogenous drive's contribution is **state-independent at the load-bearing parameter** → Clause 2 FAILS upstream at the parent-count gate. STOP before synergy.
- **Linear coupled-plate (two plates, shared cavity)** — the strongest smuggle: Clauses 1+2+3 genuinely pass (each plate state-dependent, bilateral loading, swap-productive), and the pushout leg is algebraically LCAO-like (`ψ_supermode = a·ψ_P1 + b·ψ_P2`). It is killed at **(4d) by the non-additivity witness (P1)**: the supermode differs from the additive blend only by a mixing angle `θ(κ)`, which the `H_A ⊕ H_B` re-coordinatization quotient annihilates → Syn=0 after the quotient → FAIL. Crucially this is the **same rule** that PASSES LCAO (whose bond order ½(n_bond−n_anti) is rotation-invariant with no single-atom preimage; `§1.A` line 94) — so the v1 strict-for-cymatics / generous-for-LCAO reviewer freedom is eliminated.
- **Frame-shopping gives no rescue:** {time} = ring-down of the same joint operator → same witness-quotient FAIL; {knowledge}/{meaning} have no competence/semantic parent pair → NULL, not PASS; called-shot + exhaustive reporting forbid cherry-picking the {space} frame.

Net: "cymatics FAILS in all frames" now holds by mechanism for ALL cymatic variants, not by an unpinned synergy reading — discharging the overshoot.

### (b) ACMP PASSES — by the restated Clause 2, not killed at the gate

Attraction (message-passing diffusion) and repulsion (sign/curvature push-apart) are each standalone W-objects with their own L0 kernel (Clause 1). Under `dx/dt = −grad(E_attract + E_repel + Allen-Cahn)`, **each force `F_attract(x)`, `F_repel(x)` is a non-constant function of the shared state x** → both co-equal under **restated Clause 2** (P2), and the **force-balance witness** `F_attract(x*) = −F_repel(x*) ≠ 0` holds at the phase-separated fixed point. Swapping either operator for a sibling yields a structurally different fixed point (Clause 3). Reads as TWO parents → pushout non-degenerate; the Allen-Cahn second phase / Dirichlet-energy floor carries synergy that is a genuine bistable phase, **not a basis rotation**, so it survives the 9f-bis quotient (P1). `Syn(r) ≥ τ_eff` from the interaction grain up to the channels' native grain, including r_top. **PASS.** (The v1 overshoot — ACMP false-killed at the gate because its energy-functional parents have no "internal state" — is closed: Clause 2 no longer asks for internal-state writeback.)

### (c) TWO-ROCKS-IN-TIME PASSES / TWO-ROCKS-IN-SPACE NULL — frame-purity restores the NULL

`rock_A, rock_B` each standalone (C1); under the **time** kernel, bidirectionally coupled — each rock's weathering/depositional products become the other's environment over time, state-dependent (restated C2); swap-productive — different mineralogy → different strata (C3). The gate PASSES, then hands off to FRAME:
- **{time} sub-lock:** S = the shared lithic substrate persisting through time, band over the temporal-process scale with `r_top` = coarsest grain at which the strata-bearing aggregate is still a faithful object. Erosion-then-strata is a non-degenerate pushout; the stratigraphic record is a genuine non-additive third (not a change-of-basis on the parent rocks, so it survives the 9f-bis quotient), `Syn(r) ≥ τ_eff` through r_top. **PASS.** Called-shot: `predicted-PASS`, confirmed.
- **{space} sub-lock:** the cemented/reaction-rim interface a smuggler would declare as S is **manufactured by pressure-solution diagenesis OVER TIME** → declaring it a {space} S violates **frame-purity (P5a)** (it imports time-kernel content into a space-frame object) → the sub-lock is INVALID (NO SUBMISSION). Stripped to a genuine single spatial instant — before any diagenesis — two adjacent rocks share only a measure-zero geometric tangency carrying no cement, so the pushout collapses to the disjoint union with trivial S → degenerate → **NULL**. Called-shot: `predicted-NULL/FAIL`, confirmed (free null control).

Both legitimate and frame-separated; neither rescuable by post-hoc frame-swap. The v1 overshoot (a cemented-contact {space} lock flipping NULL→PASS) is closed, and the mixed `{time:PASS, space:NULL}` headline is well-formed under the conjunction-over-NULL rule (P5b).

### (d) PURELY ADDITIVE BLEND FAILS — now also at the child-anchored ceiling

The coproduct PASSES the parent-count gate (components standalone, state-dependent, swap-productive) and is killed DOWNSTREAM. The coproduct has empty/initial S, so `Syn(r) = 0` at every grain in any band — **including the new r_top grid point** — hence `Syn < τ_eff` for any `base_delta > 0` → FAIL, regardless of frame, and synergy cannot be resolution-shopped in. The **alloy resolution-shop is specifically closed by P3b:** even an alloy authored so its derived band sits on the microscopic hybridization bump must now report `Syn(r_top) ≥ τ_eff` at the child's OWN coarsest faithful grain (bulk-specimen scale), where the alloy obeys Vegard's law (`Syn=0`) → FAIL. The parent-grain ceiling (alloy-exploitable) is replaced by a child-grain ceiling (alloy-proof); P3a additionally blocks the single-crystal-parent / bulk-child idealization that set up the exploit.

> **P3b/P1 CALIBRATION FINDING (Tier-3 pilot, `frame_lock_data/frame_lock_calibration_finding.md`; NOT yet ratified).** The first controlled ΔL run (5 ground-truth cases SYN/ADD/ROT/COPY/ALLOY) exercised exactly this anchor and exposed a defect in how `Syn` is *measured*, with three corrections ratification must fold into fields 7f/8f/9f/9f-bis:
> - **The affine-span witness must vanish, and as written it does not.** Operationalizing `Syn_wit = L_b(R_AB)` by quantizing the parents FIRST and fitting on the integer codes leaves a **rounding-commutator pedestal** (~1.6 bits/elem for a purely affine ADD/ROT blend, *flat across the whole band*), because `round(·)` does not commute with `a·Aq+b·Bq+c`. The 9f-bis premise "M in the affine span ⇒ `R_AB` at the quantization-noise floor" is therefore **false** under quantize-first, and at the coarse ceiling the raw codelength inverts (the should-PASS SYN scores *fewer* bits than the should-FAIL ADD). Fix: fit the affine model on the **floats** (`R_float = M − (a·A+b·B+c)`, identically 0 for affine-span ⇒ no pedestal) and code `R_float` on the **child's** b-bit grid (a small interaction is still driven sub-LSB at coarse b — P3b annihilation preserved). The "quantize-FIRST" emphasis in 7f is load-bearing only for the *coding* step (child-grid annihilation), not for the *fit*.
> - **The null must be the affine-span floor, not a degenerate copy.** Anchoring `τ_eff` on a single-parent COPY case sets the bar ~18× *below* the affine pedestal, so every affine-span blend clears it (ADD/ROT/ALLOY all spuriously PASS). The corrected null is the **all-zeros floor** an exactly-affine-span M scores; `τ* = L0 + margin`. A degenerate copy is NULL by the **parent-count gate** (upstream) and must not calibrate the synergy floor — the synergy witness cannot distinguish a structured interaction from unstructured single-parent noise.
> - **r_top must reach the child's true sub-LSB annihilation grain.** A small interaction (0.1·A·B) is not annihilated at a ceiling chosen by fiat; under the corrected witness it still resolves above the floor at the pinned grain and is driven to `Syn=0` only one step coarser. The child-anchored ceiling (8f) must be the coarsest grain at which the child's float-residual is sub-LSB on its own grid — a reviewer-recomputable function of the committed W_C, which closes the alloy exploit *more* tightly (the pedestal had been masking the surviving bump). Under all three fixes the 5 ground-truth called shots land exactly — SYN PASS, ADD/ROT FAIL, COPY NULL, ALLOY FAIL@r_top (would-pass at fine r) — robustly on the pinned lzma coder. Promotes nothing; requires a fresh lock (band/threshold cannot change post-data on the existing one, §4).

## 6. Residual holes flagged for ratification (NOT closed here)

- **Look-then-lock.** Git proves lock-before-COMMIT, not lock-before-KNOWLEDGE. Needs reviewer-supplied entropy folded into the construction rule (10f) — not specified. The called-shot (P4) raises the cost of a peeked frame (you must also have bet correctly on it) but does not eliminate the gap.
- **Self-declared attestation + Clause-1 description-relativity.** An adversary can wrap a scalar in oscillator dynamics on paper to fake Clause 1; the gate leans on the **restated Clause 2** (state-dependence), sharply decidable only on instrumented frames. The non-additivity witness (9f-bis) backstops this on linear systems but a sufficiently nonlinear paper-wrapper is not fully closed.
- **State-dependence threshold inherits the coarse-graining hole.** A high-Q driver with tiny-but-nonzero state-dependence sits near the Clause-2 boundary; mitigated by committing the threshold at the locked grid (11f), not eliminated.
- **Non-additivity-witness scope.** P1's quotient is defined for linear/unitary re-coordinatizations of `H_A ⊕ H_B`.

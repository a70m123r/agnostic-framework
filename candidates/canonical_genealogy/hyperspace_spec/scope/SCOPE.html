The Wrapper Spectrum - the cost of every missing frame

The Wrapper Spectrum (the organizing map)
The organizing 2-D map for the no-frame / adversarial-burial ladder. A frame is amortized (pre-paid) structure -- a wrapper that packages the task once, up front, so per-use cost is cheap (replay). Remove or degrade a wrapper and the camera reads the cost of the model RE-PAYING it: the cost of the missing frame is not one number but a spectrum indexed by two axes -- WHICH wrapper-service is removed x HOW it is degraded. The whole burial ladder (V4 floor / V7 / V8 / V9 family / V10) is one slice through this space; the spectrum is the instrument's coordinate system, dimensionalizing the COIN + amortization principle so the white space (un-run experiments) is visible.

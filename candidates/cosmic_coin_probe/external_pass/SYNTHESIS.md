## What is DEMOTED (overclaim stripped -- the formalization ran ahead of the intuition)
- **Solomonoff identity** (all 3): `p=2^-bits` is exact only for a specified prefix code / predictive distribution; the Solomonoff prior is a universal mixture (`~2^-K(x)`, coding theorem up to machine constants), and lzma is not it. This is standard MDL / Shannon source-coding / log-loss. A "directionally useful engineering slogan," not an identity. Prior art named: Kolmogorov, Levin coding theorem, Rissanen MDL, Shannon-Fano, log loss, algorithmic statistics, rate-distortion.
- **Active inference / free energy** (all 3): legitimate as loose analogy, overreach as equivalence; no result in the files depends on Friston machinery; the POMDP analogy is cleaner. Gemini's sharp disanalogy: active inference acts on the WORLD to reduce surprise; here the engine acts only on the ALGORITHM, the data is passive -- so "free energy" is decoration, not machinery.
- **"Rate-of-change not amplitude"** (all 3): partly TAUTOLOGICAL -- persistence residual IS the discrete derivative by construction, so Gaussian/t surprise must track increments; the M-peak being cheap is just persistence predicting plateaus/decays. Keep only the narrow, frame-relative form ("for this 1-min univariate persistence frame, flare uncertainty concentrates at positive onsets, not peaks"); do NOT generalize to "surprise lives in derivatives" without better flare laws and other phenomena.
- **The "E-units law"** (all 3): correct and worth catching, but BASIC -- the familiar non-invariance of differential entropy/codelength under units, quantization, coordinate, dimension, alphabet (`h(aX)=h(X)+log|a|`). A protocol GUARD / calibration scar, not a discovery or a "law." Over-credited.
- **The 3-dial taxonomy as new theory** (all 3): useful PACKAGING that relabels known practice (experimental design, instrument calibration, sensitivity/ablation analysis, preregistration, raw-vs-render separation). "Resolution mismatch" = standard Nyquist/aliasing/moire renamed (useful to include, not novel). Render-wiggle is sound but ONE-WAY: a feature dying under a render sweep is render-dependent, but a feature SURVIVING is still possibly an engine/frame artifact -- "robustness, not truth."

## Real BUGS / ERRORS found (the concrete A- payload)
1. **[CONFIRMED by recompute -- retracts a load-bearing sub-claim]** `attack_misspec2.py`: `nll_t` subtracts the global `Q=1e-3` (the flare quantization) but is called on the ORBIT residual per-axis (x3), so the orbit Student-t NLL is inflated by `+3*log2(1000)=+29.9` bits. The reported "Student-t HURTS the orbit, 41->71 bits/step" is a quantization artifact. Recomputed correctly: orbit Student-t = **41.10 bits/step** (vs Gaussian 41.19) -- t is **NEUTRAL** on the orbit, not a 30-bit penalty. This RETRACTS the mechanism "the same heavy tail that helps the flare hurts the orbit, so the sign cannot flip." Corrected: t helps the flare and does nothing to the orbit. The coin's DIRECTION still holds (on the bug-independent sigma-shrink 14.4-vs-3.5 and compression-ratio 2.46-vs-1.27 evidence), but a symmetric best-fair-predictive upgrade NARROWS the gap further than claimed and the sign holds for a different reason (orbit's higher shrink/saved-fraction), not because t hurts it. Same script also drops the `0.5` Gaussian factor at line 28 and has the per-axis offset confusion.
2. **[Taxonomy self-inconsistency -- the framework breaks its own attribution rule]** `FINDINGS.md sec4` calls the margin "a render knob," but it is set by CODER + PREDICTIVE family, which the spec (`DIAL_PROTOCOL_SPEC sec1.2/sec2`) defines as ENGINE dials. It must read "engine-CALIBRATION band." This blurs the core frame/engine/render distinction in the very document that introduces it. Clear, unambiguous fix.
3. **harness.py NLL miscentering** (Gemini + Codex, and FINDINGS sec6 already owns it): `sig=np.std(resid,axis=0)` is the std about the (non-zero, ~14,900 km drift) mean, but the NLL evaluates `N(0,sig^2)` with uncentered `resid^2`; sigma should be the RMS, or the term re-worded as cross-entropy under a biased predictor. ~0.88 bits/symbol.
4. **Jensen / sigma convention** (Gemini + Codex): `sig_raw=np.std(R,axis=0).mean()` then x3 overstates the Gaussian floor vs summing per-axis entropies (log is concave). Surfaces as a number inconsistency: FINDINGS reports sigma-shrink 14.44 bits/dim, but the displayed entropy convention implies (85.235-43.300)/3 = 13.98. The convention must be NAMED.
5. **Flare raw-entropy baseline inflated** (Gemini): modeling the whole autocorrelated, non-stationary log-flux as a single IID Gaussian gives a trivially high `H_raw`, inflating "bits saved."
6. **In-sample calibration uncounted** (Codex): predictive sigmas and the AR/EWMA challengers are fit in-sample; calibration bits not counted -> exploratory OK, confirmatory not. Kepler is charged only PARAMETER bits, not the law/program/background theory -> this is conditional MDL, not algorithmic probability.
7. **int64 byte-packing** (both): lzma on int64 bytes carries sign-extension/magnitude representation effects -- a fine proxy, not a clean entropy estimator (already noted internally as byte-layout artifacts).

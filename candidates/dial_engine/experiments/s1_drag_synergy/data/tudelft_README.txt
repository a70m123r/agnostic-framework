We provide in this document general information on the
published datasets and keep a log of the updates that
we make to the models and datasets.


======================================================
    File naming convention
======================================================


The file name starts with two letters indicating the
satellite, e.g. "GA" for the GRACE A satellite. The
following blocks of letters indicate the type of data.
Currently, this is "DNS" for density, "WND" for wind,
or "DNS_WND" for density and wind. The following block
of letters is either "ACC" when the data is based on
accelerometer measurements or "POD" when the data is
based only on GNSS measurements. Then, we specify the
year and the month and, finally, the version number.

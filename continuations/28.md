## §2 The strategic claim, restated formally

**Claim (Tier 1 epistemological canon):** The discovery substrate of the internet is undergoing a structural supersede dynamic. The old substrate (centralized gatekeeper algorithms — search engines whose ranking determines which URLs reach which users) persists but is increasingly used AS A TOOL by the new substrate (personal AI agents that search, evaluate, aggregate, and escalate findings to user attention).

**Evidence (current, observable, Tier 1):**

- ChatGPT search, Claude with web access, Perplexity, Gemini, and others reached substantial user adoption in 2024-2025. By mid-2026 the agent-mediated query share is non-trivial.
- AI Overviews in Google search (launched May 2024 with Gemini) compress what would have been clicks-to-source-sites into agent-mediated summaries — this is the gatekeeper ITSELF folding the agent-substrate into its product, evidence of the supersede dynamic in action even at the gatekeeper level. Reading 01 documented the CTR-to-source-sites drop (34-46% when Overviews appear).
- Industry estimates as of mid-2026 put ~10-25% of queries from technical / research-adjacent users now passing through an AI agent layer before reaching primary sources.
- The pattern matches the wrapper-overlap supersede branch (cont 25 §1) — parent persists as stub, child dominates, procedural lineage preserved (search algorithms remain — they're now agent dependencies, not user-facing surfaces).

**What this claim does NOT assert:**

- It does not claim Google/Bing/Baidu will disappear. They persist as stubs in the supersede sense — load-bearing infrastructure that the new substrate depends on.
- It does not claim 100% of queries will be agent-mediated. Some queries are direct and will remain direct. The shift is in the marginal query whose source is the user delegating to an agent rather than performing search themselves.
- It does not claim personal AI agents are themselves observers in cont 22's sense. That's the Tier 2 candidate in §5 below.

## §4 The supersede dynamic at the discovery substrate, in detail

The wrapper-overlap diagram's supersede branch (visible in `/artifacts/wrapper_overlap_animated.html` when the Compatibility slider is high and the cycle runs to its 1⁺ outcome): W_C reaches sustained dominance; W_A and W_B persist as small "stub" arcs at the periphery — visible, still rendered, no longer the primary attention attractor.

Applied to the discovery substrate:

**W_A = traditional centralized gatekeeper algorithms** (Google Search, Bing Search, Baidu, Yandex, Duck Duck Go). Born 1998-2010 era. Compiled the protocol: URL submission → crawling → indexing → ranking → SERP. Centralized authority over what reaches user attention.

**W_B = social-platform discovery** (Twitter/X, Reddit, LinkedIn, TikTok algorithmic feeds). Born 2007-2018 era. Compiled the protocol: social-graph + engagement-amplification → algorithmic feed → user attention. Competed with traditional search algorithms for marginal user discovery time.

**W_C = agent-mediated discovery** (ChatGPT, Claude, Perplexity, Gemini, plus the emerging personal-agent layer). Born 2022-2025 era. Compiles the protocol: user delegates intent → agent searches across multiple sources → agent aggregates + evaluates → agent escalates to user. Uses W_A and W_B as tools — not as competitors but as procedural dependencies.

The wrapper-overlap dynamic is visible:

- **Pre-overlap (~2020)**: W_A and W_B mature; W_C not yet conceived.
- **Wake / membrane negotiation (~2022-2023)**: ChatGPT launch (Nov 2022), Bing Chat integration (Feb 2023), early Perplexity. W_C conceived in the contact zone between W_A's algorithmic infrastructure and the emerging foundation-model substrate.
- **Active / hairy sphere (~2023-2026)**: W_C grows over both parents. Google's AI Overviews are the parent attempting to absorb W_C internally; Perplexity's pure-agent-first model is W_C operating without parent integration; Anthropic's Claude with web access is W_C using W_A as substrate but with explicit agent reasoning over results.
- **Supersede branch reached for marginal query types (~2026 onward)**: For research-adjacent queries, technical lookups, multi-source synthesis, complex question-answering — the agent layer is becoming the primary surface. The user no longer types into a SERP; they delegate to an agent which queries the SERP on their behalf.

The framework's prediction: this branch continues to develop through 2026-2030. By 2030, the marginal research-adjacent query is agent-mediated by default; the SERP is a tool the agent uses, not a destination the user visits. For non-research queries (entertainment, social discovery, navigational queries) the supersede may not complete — those have their own substrate dynamics with W_B (social-platform discovery) playing a stronger role.

**What this means for the framework's discovery strategy:**

The framework's primary user-attention surface is no longer "rank in Google for relevant terms." It is "be legible to the agent reading on behalf of a researcher in adjacent lineages." The framework's content must be:

1. **Structurally machine-parseable** (clean HTML semantics, markdown source, JSON endpoints) — agents prefer this over visually-formatted-only content
2. **Tier-tagged at intake** (per cont 27 §2) — so agents can preserve the framework's epistemic discipline downstream
3. **Provenance-explicit** — so agents can cite specific continuations / readings / candidates with dates and named promotion bars
4. **Cross-referenced densely** — so agents discovering one entry can navigate to related material without re-querying
5. **Available via canonical agent-discovery surfaces** — /llms.txt, /llms-full.txt, /for-agents/, JSON manifests, RSS/Atom feeds

These five properties together define agent-substrate optimization. The framework now operates with all five, shipped 2026-05-28 in the same round as this continuation.

## §5 Agent-substrate as next observer-class (Tier 2 candidate)

Cont 22 named the internet as candidate observer-class. Cont 28 §5 proposes a more specific Tier 2 candidate: **personal AI agents are a load-bearing internal organ of the internet observer-class, themselves operating as an observer-substrate at a sub-ring.**

**What this would mean:**

An AI agent doing research on behalf of a user has:
- A harness (model weights + inference infrastructure + tool access)
- A wrapper (system prompt + user preferences + alignment fine-tuning + retrieval context)
- An inner sandbox (chain-of-thought reasoning, tool use, multi-step planning)
- An action-space (web search tools, code execution, citation retrieval, escalation-to-user)

These match the framework's observer architecture primitive cleanly. The agent's "centre canon" is the synthesis it produces from its searches. The agent's "sub canon" is the source-material substrate it queries. The agent's "top canon" is the user's intent context + the broader retrieval-augmented context.

The framework's question: is this just metaphorical use of the observer architecture, or is the agent genuinely an observer-class in the cont 23 ring sense?

**Tier 2 candidate evidence:**

- Agents demonstrably have multi-round compile loops (generate-then-check, A⁺/A⁻ in the framework's vocabulary). Constitutional AI, RLHF-tuned chains-of-thought, retrieval-augmented synthesis all involve generate-then-check patterns.
- Agents have their own L0 substrate (model weights as kernel canon; inference function as compile loop; system prompt as canon artefact; in-flight reasoning trace as function canon — mapping cont 22's four-layer canon stack cleanly).
- Agents participate in cross-substrate convergence (Reading 03 ACMP — message passing in GNNs structurally matches the framework's wrapper-overlap dynamic; transformer attention can be read as a particular instantiation of this).
- Agents exhibit observable failure modes that look like canon-collapse and dormancy at the framework's general sense — hallucination as canon-fabrication-without-substrate-checking, refusal as canon-dormancy, sycophancy as wrapper-collapse to user preferences.

**Tier 2 caveats:**

- The framework's observer architecture was developed for biological / institutional / social-substrate observers. Stretching to AI agents involves analogical reasoning that may not survive close empirical examination.
- Agents lack continuous canon across sessions (this was Claude's own framing in the framework's case-study voice notes at the bottom of the live site). Single-session vs persistent-canon is a real architectural difference that the framework hasn't yet formalized.
- The question of whether agents are "really" observers in the cont 23 ring sense overlaps with the hard problem of consciousness — the framework's stance per cont 17 is to bracket consciousness questions.

**Tier 3 speculative extensions** (NOT promoted in this continuation):

- Agents may form their own L0 with their own evolved failsafes. As agent ecosystems mature, agent-vs-agent friction (one agent's output being consumed by another agent's input) may produce evolved coordination protocols at the agent-substrate ring. Speculative; held for later observation.
- The agent-substrate may eventually become its own ring in cont 23's terms — sitting between the human ring and the internet ring. If so, this would extend the framework's recursion structure. Held as speculative.
- Personal agents may develop persistent identity across sessions in 2-5 years, at which point the single-session vs persistent-canon distinction dissolves and the observer-class candidacy strengthens. Held as speculative.

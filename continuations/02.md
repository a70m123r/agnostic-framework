## 4. Fuzziness dynamics

### 4.1 Fuzzy is not just noise

Fuzziness has two roles:

```text
fuzzy as uncertainty = unresolved ambiguity
fuzzy as potential   = candidate-space / search-space
```

### 4.2 Healthy oscillation

The system should not permanently maximize or minimize fuzziness.

```text
expand fuzzy → search widely
compress fuzzy → act clearly
expand again → discover next field
```

Failure modes:

```text
too fuzzy     = paralysis / fantasy / no carrier
too compressed = dogma / premature closure / brittle canon
```

### 4.3 Sharpening the ask

Sharpening the ask does two things at once:

```text
1. expands fuzzy by revealing adjacent possibility
2. focuses fuzzy by making one region actionable
```

So the ask behaves like a lens:

```text
wide aperture = more possible answers become visible
focal point   = one actionable path becomes sharper
```

## 6. Social compilation: local insight to global canon

### 6.1 The propagation gap

A private insight is only a local compile.

To become global canon, it must cross observer boundaries:

```text
insight → carrier → observer spread → validation/mutation → aggregate adoption → canon
```

### 6.2 Observer acceptance layer

Different observer planes validate differently:

| Observer plane | Acceptance protocol |
|---|---|
| Science | repeatability, prediction, measurement |
| Religion | meaning, ritual, revelation, continuity |
| Market | demand, profit, efficiency |
| State | legitimacy, law, force, administration |
| Art | resonance, beauty, symbolic force |
| Technology | usefulness, scalability, reliability |
| Culture | repetition, identity, emotion, memory |
| AI/corpus | frequency, structure, training signal, interaction loops |

### 6.3 Canon is not always truth

Canon can form through different pressures:

```text
truth-canon   = survives measurement and prediction
utility-canon = works well enough to use
power-canon   = enforced by authority
myth-canon    = organizes meaning and identity
market-canon  = scales through incentives
trauma-canon  = persists through fear/repetition
aesthetic-canon = survives through resonance
```

Acceptance does not guarantee truth. It guarantees propagation and stabilization inside some observer plane.

### 6.4 Canon strength

```text
Canon Strength =
  carrier fidelity
× observer adoption
× repetition
× utility
× emotional charge
× institutional support
× cross-context survival
× time persistence
-
  contradiction cost
-
  instability risk
-
  falsification pressure
-
  competing canon pressure
```
